# Trancoso Fishing

## Arquivos principais
- `index.html`
- `style.css`
- `script.js`
- `assets/`

## Contato
No `index.html`, procure por:

- `SEU_EMAIL_AQUI`
- `@seuinstagram`

e substitua pelos dados reais.

Exemplo:
```html
href="mailto:contato@exemplo.com"
```

Instagram:
```html
href="https://instagram.com/nomedoperfil"
```
